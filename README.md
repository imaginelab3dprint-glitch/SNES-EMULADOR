# SNES NFC - Un solo juego

## Estructura

SNES-NFCok/
├── index.html
└── roms/
    └── juego.sfc

## Paso 1
Sube todos estos archivos a la raíz de tu repositorio de GitHub.

## Paso 2
Dentro de la carpeta `roms`, sube tu ROM legalmente autorizada.

Debe llamarse exactamente:

juego.sfc

Si tu archivo tiene otro nombre, cambia esta línea en index.html:

EJS_gameUrl = "roms/juego.sfc";

## Paso 3
Activa GitHub Pages en:

Settings > Pages > Deploy from a branch > main > /(root)

## Paso 4
Abre:

https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/

Para NFC, graba esa misma URL en tu etiqueta NFC.
